Спринт 5
Проект UI тестирования сервиса Stellar Burgers "https://stellarburgers.education-services.ru/"

1. Проверка полей регистрации
1.1 Поле Имя не должно быть пустым
1.2 Поле Email в формате логин@домен, например 123@ya.ru
1.3 Поле Пароль с требованием минимум 6 символов

1.4 Проверка ошибки при некорректном пароле

2. Проверка входа
2.1 Вход по кнопке "Войти в аккаунт" на главной странице
2.2 Вход через кнопку "Личный кабинет"
2.3 Вход через кнопку в форме регистрации
2.4 Вход через кнопку в форме восстановления пароля

3. Проверка переходов
3.1 Проверка перехода по клику на "Личный кабинет"
3.2 Проверка переходи из личного кабинета в конструктор
3.3 Проверка перехода по клику на "Конструктор" и на логотип Stellar Burgers

4. Выход из аккаунта
4.1 Проверка выхода по кнопке "Выйти" в личном кабинете

5. Раздел "Конструктор"
5.1 Проверить переход к разделу "Булки"
5.2 Проверить переход к разделу "Соусы"
5.3 Проверить переход к Разделу "Начинки"
